# Practical 09 — Personal Portfolio in MATLAB

## Write-Up
**Aim:** Create a personal portfolio GUI in MATLAB.  
**Software:** MATLAB.

## Theory
HTML (Hypertext Markup Language) is a standard markup language used to create webpages. It uses various tags to display headings, paragraphs, images, buttons, and other content. In this practical, MATLAB software is used to create a personal portfolio interface displaying personal details, hobbies, and an “About Me” section with an interactive rotating name button.

## Program
See [09_Personal_Portfolio.m](../MATLAB/09_Personal_Portfolio.m).

## Working
1. Clear the workspace and close existing figures.
2. Create the main window and colored header.
3. Add portfolio title and welcome message.
4. Create axes for the name.
5. Show branch, college, hobbies and About Me.
6. Add a **Rotate My Name** push button.
7. Button callback animates the name through 360 degrees, then resets it.

## Output
A MATLAB portfolio window with the name, Electronics & Telecommunication branch, GCOE Jalgaon, hobbies (Reading, Travelling, Painting), About Me text and rotate button.

## Conclusion
A personal portfolio was designed in MATLAB using GUI components and a button callback animation.
